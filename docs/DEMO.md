# Three-minute guided demo

Select **3-MIN DEMO** in the top bar. The five-step walkthrough is manually
advanced and paced for approximately three minutes:

1. **0:00–0:35 — Orbital context:** introduce the Jezero site map, data sources,
   cursor coordinates, and estimated local Mars time.
2. **0:35–1:10 — Terrain screen:** toggle slope/hazard layers and explain the
   coarse MOLA resolution and why zero flagged cells does not prove safety.
3. **1:10–1:50 — Plan a Marswalk:** set start and end waypoints on traversable
   cells; markers can be dragged.
4. **1:50–2:30 — Compare routes:** compare shortest, safest, and science-weighted
   routes; scrub the elevation profile to link a route sample to the map.
5. **2:30–3:00 — Check resources:** enter hypothetical capacities and run the
   round-trip GO/NO-GO model, emphasizing its limitations.

The local environment time and dust controls are illustrative. No science stops
are displayed because verified Jezero coordinates are not connected. Finish by
calling out that coarse-MOLA routes and modeled resource checks are not
operational navigation or mission approval.
